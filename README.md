## Clonar

**Mac**

```bash
cd ~/Github
git clone https://github.com/brunomcduarte96/edicao-edvid.git
```

**Windows (PowerShell)**

```powershell
cd C:\Users\MEUCOMPUTADOR\Github\Bruno
git clone https://github.com/brunomcduarte96/edicao-edvid.git
```

Se a pasta `edicao-edvid` já existir vazia, rode dentro dela: `git clone https://github.com/brunomcduarte96/edicao-edvid.git .`

## Rotina

Antes de trabalhar: `git pull`. Depois: `git add -A && git commit -m "descrição" && git push`.
