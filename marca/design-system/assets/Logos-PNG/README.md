# Logos PNG

As 13 versões do grupo **Logos** exportadas em PNG com fundo transparente, a partir dos SVGs originais.

- Assinatura: 2400px de largura. Wordmark: 2000px de largura. Símbolo: 1000px de altura. Avatar: 1024×1024px (com o quadrado de fundo).
- Escolha pela cor do fundo: `-preto` no claro, `-branco` no escuro, `-mono-*` sobre cor ou foto.
- Prefira o SVG quando o programa aceitar vetor. Use o PNG em redes sociais, buscas por imagem e editores que não aceitam SVG.
