# Logos

A logo da FalaiBruno: símbolo de três blocos e wordmark `falaibruno` com o pingo do "i" em petróleo.

- `assinatura-*`: símbolo + wordmark, a versão principal. `-preto` para fundos claros, `-branco` para fundos escuros, `-mono-preto` all black e `-mono-branco` all white, em uma cor só.
- `falaibruno-*`: só o wordmark. `-preto` / `-branco` com o pingo em petróleo; `-mono-preto` / `-mono-branco` em uma cor.
- `simbolo-*`: só o símbolo, em cor ou mono.
- `avatar-*`: o símbolo num quadrado preto ou branco, para perfis e favicon.

Tintas: preto `#0A0A0A`, branco `#FFFFFF`, petróleo `#1F6F6B`, âmbar `#E8A33D`, cobalto `#2F5BEA`. O pingo do "i" é sempre petróleo `#1F6F6B`. Nunca redesenhe ou recolora os arquivos.

As mesmas versões em PNG transparente estão no grupo **Logos PNG**; as animações do símbolo, no grupo **Animações**.
