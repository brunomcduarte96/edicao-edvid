# Field

Campo de texto com rótulo acima e linha de ajuda ou erro abaixo.

- Altura 44px, raio `r-sm` (4px), padding 12px, texto 15px, rótulo 14px SemiBold.
- Padrão: borda 1px `border`. Foco: borda 2px `fg`. Erro: borda 2px `danger` e mensagem em `danger`, curta e concreta. Desabilitado: `surface` com `fg-muted`.
- Sempre `<label for>` ligado ao `<input>`. Checkbox e rádio em 18px com `accent-color` em `fg`.
