# Card

Três tipos de card que separam o conteúdo por papel: preenchido para o principal, contorno para o secundário, inverso para o que mais importa.

- **Preenchido:** `surface`. **Contorno:** borda 1px `border`, sem fundo. **Inverso:** `inverse` com `inverse-fg` e rótulo em `highlight`.
- Raio `r-md` (6px), padding `sp-6` (32px; `sp-5` em cards pequenos), gap interno 12px.
- Estrutura: eyebrow opcional, título `h3`, texto `body`.
- Sem sombras, sem bordas laterais coloridas. Um card inverso por tela, no máximo.
