# Progress

Barras de progresso contínuo e de etapas.

- **Contínua:** trilha `surface`, barra `accent`, 8px de altura, raio `r-sm`. Rótulo com etapa e porcentagem acima.
- **Etapas:** cinco segmentos de 8px, raio `r-xs`, gap 4px, na progressão `gray-3` → `amber` → `cobalt` → `teal` → `fg`. Sempre com legenda.
