# Tag

Rótulos retangulares para categorias e status, em eyebrow (12px SemiBold, CAIXA ALTA, +0,08em).

- Raio `r-xs` (2px), padding 6×10px. Sem formato de pílula.
- Neutra em `border`; destaque em `highlight` com `highlight-fg`; `accent`, `info` e `inverse` com seus textos `-fg`.
- Status: Concluído (`accent`), Em atenção (`highlight`), Informação (`info`), Erro (`danger`). Sempre com palavra, nunca só cor.
